content-box

width and height apply only to the content. Padding and border are added extra, on top of that(box grows)
width: 200px;
  padding: 20px;
  border: 5px
Total rendered width = content(200) + padding(20+20) + border(5+5) = 250px

border-box

width and height include the padding and border inside them. Nothing gets added — the content area just shrinks to fit.
width: 200px;
  padding: 20px;
  border: 5px
Total rendered width = 200px, box is 200px contents inside the box shrink to adjust with the padding. box dont become big.
Content area shrinks to: 200 − padding(20+20) − border(5+5) = 150px
