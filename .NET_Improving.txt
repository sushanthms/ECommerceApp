SQL Server Execution Plans
Table Scan
scanning the whole rows one by one

Index Seek
using the index to directly navigate towards the matching SKU

Index Scan
scans the indexes one by one

SQL Server's optimizer looks at the query and available indexes and chooses the plan.

It looks at things such as
available indexes
table size
filtering conditions
estimated number of matching rows
statistics
and creates an execution plan.

Referential integrity means a foreign key value in one table must refer to an existing primary key value in the related table.
If a foreign-key constraint is violated
we are inserting a foreign key value that is not present in the original table
the database rejects the operation and we get an error(DbUpdateException)

Concurrency means multiple requests/users are accessing or modifying data at around the same time.

Optimistic concurrency assumes that conflicts are uncommon, so multiple requests are allowed to work with the data
Before saving, the system checks whether somebody else changed the data.
