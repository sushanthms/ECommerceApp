ASP.NET Core has a Dependency Injection container that keeps track of these services.

Model binding is the process where ASP.NET Core takes the incoming request data and supplies it to the C# action parameters/models.

public AuthController(AppDbContext context)
context is provided through Dependency Injection.

_context is a variable that holds the AppDbContext object, which gives us access to the database.
The AppDbContext object is passed into the constructor through the context parameter, and then we assign that same object to _context.
So context and _context are two variables referring to the same AppDbContext object.

Task represents an operation that will complete in the future.
IActionResult represents the HTTP response that the controller sends back to the client. return Ok, return BadRequest, return Unauthorized.

public async Task<IActionResult> Login(LoginModel model)
This is an asynchronous controller action called Login. It receives a LoginModel from the request, performs asynchronous work, and returns an HTTP response.

[FromBody] tells ASP.NET Core to get the parameter data from the HTTP request body

export const updateProduct = async (id, product, token) => {
    const response = await axios.put(`${API_URL}/${id}`, product, {
        headers: {
            Authorization: `Bearer ${token}`
        }
    });
    return response.data;
};

The first argument of axios.put() is the request url.
The second argument of axios.put() is the request body.

product = {
    name: "Phone",

    stock: 5

Here product is a JavaScript object, so Axios sends it as JSON.
ASP.NET Core's model binding + JSON deserialization handles it.

when do we use [FromForm]?
Only when the frontend sends form-data

| What we're sending  | Frontend          | Backend           |
| ------------------- | ----------------- | ----------------- |
| Normal JSON data    | JavaScript object | DTO/model         |
| File                | FormData          | IFormFile         |
| Multiple files      | FormData          | List<IFormFile>   |
| Normal data + files | FormData          | [FromForm]        |

Content-Type is an HTTP request header.
Content-Type: application/json
Content-Type: multipart/form-data
It tells the backend what format of data is in the request body

ASP.NET Core sees Content-Type: application/json and understands that the body is JSON
so it needs a JSON input formatter to convert that JSON into the expected C# object.
ASP.NET Core has built-in support for JSON.
