Entity Framework Core communicates with the SQL server. It makes the database interaction easier using C#.
var users = await _context.Users.ToListAsync();
EF Core converts this kind of C# operation into appropriate SQL/database operation.

.NET is the platform that provides the runtime, libraries, and tools for building/running the code.
ASP.NET Core is the web framework on .NET that is uses to build the API.

.NET SDk contains the tools to create, build, and develop .NET applications.
It contains compiler, .NET CLI, build tools, project templates, libraries, tools.

dotnet create new webapi
it creates a project template. it creates program.cs, appsettings.json, projectname.csproj
projectname.csproj contains information about the project such as packages, dependencies, project configurations.

dotnet run
it reads the csproj file, restores required packages, compiles the C# code, creates application, starts the application, kestrel web server starts

NuGet is the package ecosystem/package manager for .NET.

Program.cs is where the ASP.NET Core application is configured and started.

var builder=WebApplication.CreateBuilder(args);
Creates a builder
creating and configuring a web application. CreateBuilder creates a builder object that we use to configure our application.
command-line arguments can be passed to the application. application can use command-line configuration if needed.

builder.Services is where we register services that our application needs.

builder.Services.AddControllers(); It adds controller services to the application's service collection

A service is generally a class/object that performs some work for our application.
ASP.NET Core has a Dependency Injection container that keeps track of these services.

Model binding is the process where ASP.NET Core takes the incoming request data and supplies it to the C# action parameters/models.
public IActionResult Login(LoginModel model)
model is NOT dependency injected. It checks whether the data matches the LoginModel DTO type.
It is mainly checking/mapping the shape and types of the incoming data to the model.

{
    "email": "abc@gmail.com",
    "password": "12345"
}

matches:

public class LoginModel
{
    public string Email { get; set; }
    public string Password { get; set; }
}

public AuthController(AppDbContext context)
context is provided through Dependency Injection.

_context is a variable that holds the AppDbContext object, which gives us access to the database.
The AppDbContext object is passed into the constructor through the context parameter, and then we assign that same object to _context.
So context and _context are two variables referring to the same AppDbContext object.

Task represents an operation that will complete in the future.
IActionResult represents the HTTP response that the controller sends back to the client. return Ok, return BadRequest, return Unauthorized.

public async Task<IActionResult> Login(LoginModel model)
This is an asynchronous controller action called Login. It receives a LoginModel from the request, performs asynchronous work, and returns an HTTP response.

A DTO is an object that is used to carry only the data that needs to be transferred between the client and the backend.

AppDbContext is the main EF Core object that represents the connection/session with the database.
It contains DbSets representing the database tables.
